    Instalar o CLI

    O CLI é um programa de linha de comando, o chamados. Ele é um único arquivo, sem instalador.

    1. Baixe o seu sistema

    Windowsx86_64 (.zip) Linuxx86_64 (.tar.gz) Linux ARMarm64 (.tar.gz) macOSApple Silicon (.tar.gz)

    2. Descompacte e coloque no PATH

    Windows: descompacte o .zip e coloque o chamados.exe numa pasta que esteja no PATH (ou use-o direto da pasta onde descompactou).

    tar -xzf chamados-*-linux-x86_64.tar.gz
chmod +x chamados
mkdir -p ~/.local/bin && mv chamados ~/.local/bin/
chamados --version

    No macOS, se o sistema bloquear o programa por vir da internet: xattr -d com.apple.quarantine chamados.

    3. Configure e entre

    # uma vez: diga qual é o seu SUAP e o seu usuário
chamados profile init --base-url https://suap.ifrn.edu.br/ --username seu_usuario

# a senha vai por variável de ambiente (nunca por argumento)
export SUAP_PASSWORD='sua_senha'          # PowerShell: $env:SUAP_PASSWORD = 'sua_senha'
chamados login

chamados list --meus

    Só os cookies da sessão ficam salvos; a senha não. Para saber se a sessão ainda vale: chamados session-status.
